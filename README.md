File Manager


Introduction

File Manager is a simple Python-based project that allows users to create, read, write and update text files using a menu-driven program.
This project is developed using basic Python concepts such as functions, loops, conditional statements, exception handling and file handling.

Features

The File Manager provides the following operations:
1.	Create File – Creates a new empty file and stores its name in the database.
2.	Read File – Opens an existing file and displays its content.
3.	Wipe And Write – Deletes the previous content of a file and saves new content.
4.	Update File – Adds new content to an existing file without removing the previous content.
5.	Exit – Terminates the program.

Technologies Used

•	Python
•	File Handling
•	Exception Handling
•	Conditional Statements
•	Loops

•	User-Defined Functions

Files Used

•	main.py – Contains the main program and all file management functions.
•	database.txt – Stores the names of recently created files.

How To Run

1.	Install Python on your computer.
2.	Download or copy the project files.
3.	Open the project folder in VS Code or any Python IDE.
4.	Run the main.py file.
5.	Select the required operation from the menu.
6.	Follow the instructions displayed on the screen.

Concepts Used

•	open() – To open and access files.
•	read() – To read file content.
•	write() – To write new content.
•	append mode ("a") – To add content without deleting existing data.
•	write mode ("w") – To overwrite existing content.
•	try-except – To handle file-related errors.
•	Functions – To divide the program into different operations.
